# Лендинг FidRid

Статическая страница на двух языках, публикуется через GitHub Pages:
**https://svalia.github.io/fidrid-landing/**

Приложение живёт в отдельном репозитории: [svalia/FidRid](https://github.com/svalia/FidRid).

## Что где лежит

| Путь | Что это |
| --- | --- |
| `index.html` | Страница целиком, стили инлайновые (так её отдал макет) |
| `i18n.js` | Двуязычность: словарь, выбор языка, подмена документов |
| `responsive.css` | Адаптив, дописан поверх макета |
| `css/` | Дизайн-система: токены, базовые стили, шрифт Golos Text |
| `assets/` | Логотип, QR-код, фавиконы, OG-превью |
| `Legal/` | Условия использования, политика конфиденциальности, согласие на обработку данных |
| `source/` | Исходный артефакт дизайна, из которого собрана страница |
| `tools/` | Скрипты пересборки |

## Языки

Страница открывается на русском или английском без участия пользователя:

1. если человек раньше переключал язык вручную, берётся его выбор из `localStorage`;
2. иначе смотрим `navigator.language`: русский язык системы - русская версия, любой другой - английская;
3. переключатель в шапке меняет язык и запоминает выбор.

Русский текст лежит прямо в разметке, английский - в словаре `DICT` внутри `i18n.js`:
скрипт обходит текстовые узлы и подменяет совпадения. Заодно меняются `<title>`,
описание, OG-теги, `alt` у картинок и ссылки на PDF.

Чтобы страница не мигала русским перед показом английского, язык определяется коротким
скриптом в `<head>` ещё до отрисовки.

## Юридические документы

В футере три ссылки, у каждой свой файл на каждом языке:

| Ссылка | Русский | Английский |
| --- | --- | --- |
| Условия использования | `Legal/Terms_of_Use_Ru.pdf` | `Legal/Terms_of_Use_En.pdf` |
| Политика конфиденциальности | `Legal/Privacy_Policy_Ru.pdf` | `Legal/Privacy_Policy_En.pdf` |
| Обработка персональных данных | `Legal/Consent_to_Personal_Data_Processing_Ru.pdf` | `Legal/Consent_to_Personal_Data_Processing_En.pdf` |

Чтобы обновить документ, достаточно положить новый PDF под тем же именем. Если имя меняется
или добавляется язык - правится словарь `DOCS` в начале `i18n.js`, разметку трогать не нужно.

## Пересборка из макета

Страница собрана из артефакта Claude Design (`source/FidRid Landing.dc.html`). Сам по себе
он не статический: в браузере подгружает React и Babel с CDN и рисует разметку на лету.
Для лендинга это лишний вес и пустая страница для поисковиков, поэтому страница «запечена».

Если дизайн обновится, кладём новый экспорт в `source/` и повторяем:

```bash
node tools/bake.mjs "file://$PWD/source/FidRid Landing.dc.html" /tmp/baked-raw.html
python3 tools/assemble.py
```

`bake.mjs` открывает макет в headless Chrome, дожидается отрисовки и снимает готовый DOM.
Попутно он чинит две вещи, которые теряются при обычной сериализации: CSS-правила, вложенные
рантаймом через CSSOM (это hover-состояния), и градиентную заливку текста.

`assemble.py` собирает из этого `index.html`, `i18n.js` и `responsive.css`: переносит стили,
добавляет мета-теги и подключает документы.
